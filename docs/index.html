01 · 图层结构

从分解的图层，
到一张完整的画面

PSD 不是一张图片，而是一棵图层树。psdkit 读取每一层的像素、蒙版、混合方式与参数，再按 Photoshop 的规则把它们合成回来。

02 · 处理流程

读取、编辑、渲染、导出

每一步都是独立、有预算、可取消的 Go 调用。不支持的特性返回结构化错误，而不是一张“看起来差不多”的图。

  1. {% include icon.html name="file" px=22 %}

    读取

    只索引结构，不预先解码像素；按图层、通道、区域和原位深按需读取。

    OpenDocument · DecodeChannel
  2. {% include icon.html name="sliders" px=22 %}

    编辑

    稳定 LayerID 定位，改名、显隐、不透明度、像素替换、增删图层与智能对象内容。

    OpenEditor · SetOpacity · ReplaceContents
  3. {% include icon.html name="layers" px=22 %}

    渲染

    在支持范围内实时重绘整图、区域、分块与画板；保存预览与实时结果分开报告。

    RenderSource · Composite
  4. {% include icon.html name="download" px=22 %}

    导出

    写回可继续编辑的 PSD/PSB，未改动的数据尽量保持原字节；或编码 PNG / JPEG。

    SavePSD · Encode

03 · 接入方式

写几行代码，
画面真的会变

Go WebAssembly 在浏览器中打开模板PSD。点选印花或上传自己的图片，自动替换共享智能图层并重绘成衣效果，也可下载 PNG 或编辑后的 PSD。

main.js 
import { PsdkitClient } from './demo/sdk/client.js';

const engine = new PsdkitClient({ workerURL: './demo/wasm/worker.js' });
await engine.ready();
const file = await engine.call('asset.put', { bytes: psdBytes, kind: 'document' });
const doc = await engine.call('document.open', { args: [{ $asset: file.data.asset }] });
// ↓ 启动引擎后，这里会追加你实际执行的调用
editor, err := psdkit.OpenEditor("muban.psd")
if err != nil {
	return err
}
defer editor.Close()
// ↓ 与左侧浏览器调用一一对应的 Go 代码
