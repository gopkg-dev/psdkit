### 本版重点

本版扩展受控编辑与保存工作流，并同步 Go API、浏览器桥接、能力矩阵和开发任务面板。

- **混合与蒙版编辑**：新增混合模式、剪贴、Blend If 和高级混合设置接口；支持像素蒙版新增、删除和属性编辑，以及矢量蒙版的有限生命周期编辑。
- **智能对象来源与变换**：读取当前来源原字节，扩展 PNG/JPEG 与扁平 RGB8 TIFF 内容处理；TIFF 支持 LZW、Deflate 与 Predictor 2。在无活动 Warp 的受支持实例上修改四角变换，保留共享来源及其他实例。
- **自动更新预览**：受支持的智能滤镜参数编辑可直接从当前来源重绘；现有顶层 RGB8 画板的子层编辑可自动合成并保存，无需额外提供预览图。
- **蒙版与图层效果组合**：补齐无羽化矢量／双蒙版的颜色叠加，以及显式阴影近似下的纯阴影和阴影＋颜色叠加，覆盖保存、重开与继续编辑。
- **渲染与格式修复**：完善调整图层参数保存、纯 Master Lightness、渐变恒定分量、单像素图案及禁用蒙版／效果处理；补充通道、蒙版和 TIFF 读取回归测试。
- **文档与进度**：更新使用指南和能力矩阵，新增可搜索、按状态和优先级筛选的任务面板；验收证据与后续计划分别展示。

### 使用范围与升级说明

- 仍需 Go 1.27.3 或更新版本，核心库只依赖标准库。
- 新接口与自动预览均有明确的文档位深、图层类型、来源格式和组合限制；不支持的情况返回错误，或要求调用方提供准确像素。
- 阴影、Warp、文字与部分滤镜的近似仍需显式开启。此次扩展不表示任意 Photoshop 文档、任意 Warp 或全部高级效果都已支持。
- 新增能力已覆盖最小回归、编辑保存重开、预算和失败路径测试；完整支持边界以此 Tag 中的能力矩阵与 API 文档为准。
